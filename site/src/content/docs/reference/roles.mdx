---
title: Roles and permissions
description: What viewers, editors and managers can do on a trip.
---

Every person on a trip has one role. Roles rank **viewer**, then **editor**, then **manager**.

| Can they…                                      | Viewer | Editor | Manager |
| ---------------------------------------------- | :----: | :----: | :-----: |
| See the itinerary, reservations, documents     |  Yes   |  Yes   |   Yes   |
| Edit the itinerary and other trip content      |   No   |  Yes   |   Yes   |
| See the Budget tab                             |   No   |  Yes   |   Yes   |
| Edit the trip (including its cover)            |   No   |  Yes   |   Yes   |
| Open the Share dialog and manage collaborators |   No   |   No   |   Yes   |
| Leave the trip                                 |  Yes   |  Yes   |   No    |

The person who created the trip can't leave it either, and managers can't leave.

Roles take effect immediately, even on a trip someone already has open.

Separately, an **Admin** manages the Arrivo server (users, health, activity). Being an admin does not give access to anyone else's trips. See [Administration](/arrivo/guide/admin/).
