---
title: Map
description: See a trip's places on a map, whole trip or one day at a time.
---

The **Map** tab shows the places in your trip as numbered pins. Choose **Whole Trip** to see everything, or pick a single day to focus on it.

:::note[The map needs a Mapbox token]
Maps, place search and route previews use Mapbox. If you run Arrivo yourself, an admin must set `MAPBOX_ACCESS_TOKEN`. Without it the Map tab stays empty and place search is unavailable. See [Self-hosting](/arrivo/self-hosting/#configuration).
:::

Places come from the events you add to your itinerary, so add a place to an event to see it on the map. A day's route strip uses the same places.
