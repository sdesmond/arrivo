## 1. Sign in

Open the address of your Arrivo server. A new install walks the first person through creating the admin account; everyone else receives a setup link from an admin. See [Account and security](/arrivo/guide/account/).

## 2. Create a trip

Choose **New Trip**, enter a title, and optionally a destination and a date range. Dates can be added later. Arrivo opens the new trip with **Day 1** expanded.

## 3. Plan your days

Add events and reservations to each day, then drag to reorder. Arrivo warns you when two events overlap. See [Day planning](/arrivo/guide/day-planning/).

## 4. Invite people

Share the trip with travel companions and pick what each can do. See [Sharing and roles](/arrivo/guide/sharing/).

## 5. See it on the map

Open the **Map** tab to see the places in your trip. See [Map](/arrivo/guide/map/).
