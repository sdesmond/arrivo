## Glossary / Data Model

- 2026-06-13: Reservation Types for v1 — Flight, Train, Bus, Ferry, Rental Car, Lodging, Cruise (added Bus/Ferry beyond the brainstorm's list; restaurants etc. remain plain Itinerary events, not Reservations).
- 2026-06-13: Time anchor — single `startTime` (required) for all types; `endTime` required for Lodging, Rental Car, and Cruise (window-based "stays"), optional for Flight, Train, Bus, Ferry (point-to-point). Revised from initial "always optional" decision.
- 2026-06-13: Linked Event labels per type — Lodging: Check-in/Check-out, Rental Car: Pickup/Return, Cruise: Departure/Return (all three required pairs); Flight/Train/Bus/Ferry: Departure/Arrival (Arrival optional). If `endTime` absent, only the start event is generated.
- 2026-06-13: Add Reservation flow — type picker shown immediately on tapping "Add," before the rest of the dialog, so subsequent fields (start/end labels) reflect the chosen type.
- 2026-06-13: Reservation fields uniform for v1 (no type-specific schema fields) — type, startTime, optional endTime, provider, optional confirmationCode, optional free-text notes. Type-specific details (flight number, room number, etc.) go in notes; can be promoted to first-class fields later if needed.
