- (event) Confirmed PRD source: prd-packt-2026-08-07/prd.md; extracted Trip Notes UX constraints.
- (decision) Harrison captures quick trip-wide reminders while planning, scans and refers to them to prepare, and adds/views the same general-trip notes during travel; notes must be easy to scan, view, create, and delete.
- (decision) Trip Notes inherits current Packt responsive UI, collaboration permissions, accessibility, privacy, and interaction standards; failed saves use the same toast behavior used elsewhere in the app.
- (decision) Trip Notes occupies the existing Notes tab on trip detail. Empty state uses Packt Empty with New Note; populated state uses the existing compact outline add action at the upper right. Manual reorder uses the Packing List drag handle with pointer and keyboard support. Delete uses the existing one-step confirmation dialog. All visual tokens, responsive behavior, dark mode, motion, focus, target sizing, and accessibility inherit current Packt standards.
- (override) Key-screen mock must follow existing itinerary Event pattern: title/body edit in place with no bulky boxed fields; visible drag handle is reorder control with no visible Move up/down buttons; delete is the same trash icon control used elsewhere.
- (decision) Approved corrected Notes-tab key mock using itinerary Event anatomy: inline editing, drag handle, and Trash icon. Empty, populated, and expanded states are mocked; delete confirmation and save-failure recovery remain spine-only.
- (event) spines finalized; approved Event-style reorder retained as documented WCAG 2.5.7 non-conformance
