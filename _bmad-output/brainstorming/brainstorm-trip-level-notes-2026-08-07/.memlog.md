- (direction by user) user chose Creative Partner mode; asked coach to choose 3 techniques
- (decision by coach) coach selected technique batch: Job to Be Done, Trait Transfer, Kill the Crown Jewel
- (technique) started Job to Be Done
- (insight by user) notes are for logistics/general reminders/thoughts, not confirmation numbers (docs) or day-specific stuff (day notes already exist per-day)
- (idea by coach) trip-level notes = pre-trip admin/reminders not tied to a specific day and not document-worthy (passport expiry check, ask Jamie re: dietary needs, bring adapter)
- (insight by user) usage pattern is task-like: write during planning, come back and check things off over time; occasional reference during the trip itself
- (decision by user) boundary: notes must not become another checklist UI — checklists already covered by itinerary and packing list
- (technique) started Trait Transfer
- (idea by user) Google Keep is the reference: fast capture + fast visual scan/find; grid isn't Packt's language, but list-based version of the same trait could work
- (decision by user) grafted trait: title + one-line preview (Keep-style) in a vertical list, not title-only-collapsed like packing list
- (decision by user) title is optional; first line can double as the preview/implicit title when no title given
- (decision by user) capture entry point stays consistent with existing app pattern: Empty-state (icon/title/description) + 'New X' button, like packing lists/documents — not a Keep-style always-visible input bar
- (technique) started Kill the Crown Jewel
- (idea by user) one long running note (rejected) instead of discrete entries
- (insight by user) discrete entries validated: single-doc kills both goals (scan-ability breaks, and multiple docs are searchable where one blob isn't)
- (decision by user) vertical list (not cards/grid) with in-place accordion expand for quick interaction, rather than opening a dialog
- (insight) FINAL DESIGN: new Trip Notes section (trip-level, separate from per-day notes). List of discrete note entries, each with optional title + always-visible first-line preview (Keep-inspired, list not grid). No checkboxes/task state ever (owned by Packing List/Itinerary). Empty state + 'New Note' button matches packing-list/documents pattern. Tap a row to expand in place (accordion), no dialog. Original packing-list-style mechanism (discrete collapsible entries) validated; only the collapsed state changed from title-only to title+preview.
